# Celebrio Core Website Starter

Brand: Celebrio
Tagline: Celebrate Every Moment

This starter is designed for the existing Next.js + TypeScript + Tailwind project.

It intentionally avoids third-party SaaS dependencies and external image/CDN dependencies.
Copy the files into `apps/web` in the existing Celebrio project.

## Included

- Responsive navigation
- Hero section
- Wedding planning process
- Services
- Why Celebrio
- Consultation CTA
- Footer
- Basic design system in globals.css

## Next steps

1. Copy `app/page.tsx` and `app/globals.css` into `apps/web/app/`.
2. Copy the `components/` folder into `apps/web/`.
3. Run `npm run dev` from `apps/web`.
4. Open http://localhost:3000.

This is the core public website. Client portal, PM portal, authentication,
MySQL, API, payments, scheduling, contracts, messaging, reporting and
admin modules will be added in later phases.
